# 비 오는 골목 / 雨の路地

## 실행
01_비오는골목.html을 최신 Chrome 또는 Edge로 여세요. 파일 안에 Three.js 0.170.0, 모든 모듈, 인체 GLB를 포함했습니다. 인터넷이나 설치, 로컬 서버가 필요하지 않습니다. WebGL 2를 지원하는 그래픽 환경이 필요합니다. 약 30MB이므로 처음 열 때 잠시 기다려 주세요.

웹 배포 주소(소유자 로그인 필요): https://rain-ramen-atelier-oct29.sangbeen0912tlsrn.chatgpt.site

마우스 드래그: 회전 / 휠: 확대·축소. 기본 구도, 식사 자세, 조리 공간 카메라를 선택할 수 있습니다. 일시정지, 비, 초점, 단색 보기를 전환할 수 있습니다.

## 제출 파일
1. 01_비오는골목.html: 오프라인 단일 파일 실행본
2. 02_prompt_coach.json: 사용자의 요구, 개선된 실행 지시문, 금지 사항, 검증 기준, 실제 확인 상태를 담은 독립 JSON. 특정 Prompt Coach 서비스의 공식 내보내기 형식이 아니라 일반 JSON 형식입니다.
3. 03_발표자료.pptx: 편집 가능한 6장 발표 자료. 표지 이미지는 사용자 제공 참고 이미지이며 실행 화면이 아닙니다.
4. 편집가능_소스.zip: index.html, scene.js, assets, 출처 문서. 소스 실행은 해당 폴더에서 `python -m http.server 8000` 후 http://localhost:8000 을 여세요. Python은 소스 개발 시에만 필요합니다.

## 구현
- 실제 메시로 만든 건물·받침대·ㄱ자 카운터·기와·등롱·조리대·그릇·자전거·화분
- CC0 MakeHuman 기반 Sam의 인체·의상·머리카락·손가락·신발과 스킨 리그 사용. 원통 조립 인물 아님
- 1 단위 = 1m. 좌석 .44m, 카운터 .73m, 높이 차 .29m
- 원본 앉기 자세에서 골반의 뒤쪽 이동을 보정
- 고정된 팔 길이를 유지하는 2본 IK, 그릇·입 기준 목표 위치, 손님별 위상 차
- 재질별 거칠기·금속성, 절차적 목재 결·표면 요철, 그림자, 평면 수면 반사
- 깊이 텍스처 기반 BokehPass, 회전·확대에 맞춘 초점 거리, 비·김·파문

## 확인 범위와 한계
관절의 수치 위치, 앉은 골반 보정, 상판/좌석 치수, GLB 파싱, 모듈 의존성과 JSON 형식을 확인했습니다. 실제 브라우저의 렌더 결과, 자연스러운 식사 자세, 손가락과 젓가락의 정밀한 그립, 모든 시점의 관통 여부 및 성능은 확인하지 못했습니다. 로컬 서버는 연결 시간 초과, 파일 URL은 브라우저 정책 차단, 비공개 배포 사이트 로그인은 자동 승인 검토에서 차단되었습니다.

따라서 참고 이미지와 동등한 사진적 완성도나 모든 자세 조건의 합격을 보증하는 최종 검증본으로 표시하지 않습니다. 인체는 동일 모델을 복제하고 의상 색을 조정했습니다. 얼굴 다양성은 제한적이며 주인장의 조리복은 원래 의상 색상 변경과 추가 앞치마/모자입니다. 손가락을 젓가락 그립 전용으로 다시 리깅하지 않았습니다.

## 수정 원칙
특정 부분만 수정할 때 요청하지 않은 인물·건물·소품·색감·조명·카메라는 유지합니다. 가구 높이를 바꾸면 그릇과 소품 높이, 손의 목표, 충돌 여유를 연결해서 조정해야 합니다. 원래 코드와 변경 항목을 함께 기록합니다.
